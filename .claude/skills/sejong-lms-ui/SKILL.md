# 세종대 AI 학습 공간 UI 작업 규칙

## 작업 시작 전
1. 프로젝트 루트의 `DESIGN.md`를 읽는다 (이미 이 세션에서 읽었으면 생략). 학생·교수 웹 흐름도 설계안이 기준이다.
2. 만들 화면에 필요한 컴포넌트가 `src/components/`에 이미 있는지 먼저 찾는다.
   - 헤더·사이드바·탭은 `src/components/shell/`의 `AppShell`, `AppHeader`, `AppSidebar`, `SpaceTabs`, `RoleBadge`를 재사용한다.
   - 역할·메뉴·사용자는 props로 넘긴다.
   - 없을 때만 DESIGN.md 4장 이름으로 새로 만든다.

## 작성 규칙
- 색·간격·모서리는 `src/app/globals.css` `@theme` 토큰 클래스만 사용한다. `bg-[#...]` 같은 임의값 금지.
- 주 색은 크림슨 `sejong`이다. 면으로 크게 칠하는 것은 제출 버튼 하나뿐이고, 나머지는 글자색이나 `sejong-soft` 배경으로만 쓴다.
- 모서리: 입력·버튼·세그먼트는 `rounded-control`(6px), 카드·블록·말풍선은 `rounded-block`(8px).
  - `rounded-full`은 상태 배지, 원형 전송 버튼, 이니셜 원에만 쓴다.
- 컴포넌트는 props로 데이터를 받고, 목데이터를 직접 import하지 않는다 (페이지가 넘긴다).
- 화면 문구는 한국어. 학생 화면 해요체, 교수 화면은 간결한 존댓말.
  - 설계안에 고정된 배너·안내 문구는 설계안 문구를 그대로 쓴다.
- 접근성:
  - 모든 버튼·입력에 보이는 라벨을 단다.
  - 키보드 포커스 링은 `--color-info` 2px(globals.css 기본값)이다.
  - 정답/오답을 색만으로 구분하지 않고 "맞음/틀림" 텍스트를 함께 표시한다.
- 슬라이더 확신도는 숫자를 항상 옆에 표시한다.

## 허용 범위가 정해진 표현 (DESIGN.md 7장)
- **말풍선**: 사용자 질문에만 쓴다(`bubble` 배경). AI 답변은 "AI" 배지 + 배경 없는 문서형 문단 + 개념 카드 + 근거 칩으로 보여준다.
- **가운뎃점(·)**: 짧은 메타 정보에만 쓴다. 예: "3주차 강의자료 · p.12", "학생 · 데모", "판정 3/3 · 확신도 3/3". 문장을 이어 붙이는 데는 쓰지 않는다.
- **버튼 끝 화살표(→)**: 다른 화면으로 이동하는 보조 버튼에만 쓴다(예: "검증 챌린지 시작 →"). 제출·저장 같은 동작 버튼에는 쓰지 않는다.
