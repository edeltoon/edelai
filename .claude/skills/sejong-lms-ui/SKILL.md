# 세종대 LMS 스타일 UI 작업 규칙

## 작업 시작 전
1. 프로젝트 루트의 `DESIGN.md`를 읽는다 (이미 이 세션에서 읽었으면 생략).
2. 만들 화면에 필요한 컴포넌트가 `src/components/`에 이미 있는지 먼저 찾는다. 있으면 재사용, 없을 때만 DESIGN.md 4장 이름으로 새로 만든다.

## 작성 규칙
- 색·간격·모서리는 `src/app/globals.css` `@theme` 토큰 클래스만 사용한다. `bg-[#...]` 같은 임의값 금지.
- 컴포넌트는 props로 데이터를 받고, 목데이터를 직접 import하지 않는다 (페이지가 넘긴다).
- 화면 문구는 한국어. 학생 화면 해요체, 교수 화면은 간결한 존댓말.
- 접근성: 모든 버튼·입력에 보이는 라벨, 키보드 포커스 링(`--color-lms-blue` 2px), 색만으로 정답/오답을 구분하지 않고 "맞음/틀림" 텍스트를 함께 표시.
- 슬라이더 확신도는 숫자를 항상 옆에 표시한다.

## 하지 말 것 (DESIGN.md 7장 요약)
그라데이션, 보라/네온, 반짝이 아이콘, 로봇 일러스트, 채팅 말풍선, 카드 그림자, 알약 버튼,
가운뎃점 메타 문구, 버튼 끝 화살표, 섹션 등장 애니메이션. 움직임은 판정 공개 연출 하나뿐.
