# 교수 수업 분석

`/professor/course/phil/analysis`에서 서양철학 제출 현황을 집계한다.
학생 기록과 같은 읽기 전용 어댑터·구독 훅을 사용한다. Supabase 코드는 변경하지 않았다.
이 기능 브랜치는 교수 기록 PR #8의 코드를 기반으로 한다.

- 학생·챌린지별 최신 제출만 포함한다. 전체 선택의 평균 단위는 학생 수가 아닌 최신 제출 건이다.
- 수강생 명부가 없으므로 제출률은 계산하지 않는다.
- 평균 점수(7점 만점), 확신도 보정 정확도, 점수 구간, 해설 후 설명 작성 건수를 표시한다.
- 예시/서버로 표시/출처 미확인 채점의 개수를 함께 표시한다. 집계는 이 출처들을 모두 포함하며 로컬 값은 신뢰된 성적이 아니다.
- 주장 오답은 저장된 `claimGrades[].judgmentCorrect`를 사용한다. 정오답 기록이 없으면 추정하지 않는다.
- 챌린지 ID와 주장 ID를 함께 구분한다. 중복·잘못된 정오답 목록은 오답 집계에서 제외하고 경고한다.
- 학생 답안의 '틀리다' 선택 자체는 오답이라는 뜻이 아니다.
- 데이터가 없으면 평균은 '—'이며, 예시는 명시적으로 선택할 때만 표시한다. 예시는 저장하지 않는다.
- 새 AI 분석·채점, 수업 개선 제안, 평가 확정은 포함하지 않는다.

Supabase가 준비되면 `useRecords`의 조회/구독을 서버 기록 API로 바꾸고 동일한 `StudentView`를 제공한다.
원문 조회는 학생 기록 탭에서 가능하다. 집계에 사용된 학생 기록은 같은 origin의 localStorage로 한정된다.

검증: 재시도 최신값 선택, 챌린지 필터, 주장 ID 분리, 소수 점수 구간, 누락·잘못된 정오답 기록 테스트.

## 채점 대기 반영
reasoning 또는 concept가 null인 최신 제출은 채점 대기 건수로 표시한다.
점수 평균과 점수 분포는 두 항목 모두 완료된 제출만 사용한다. 완료 기록이 없으면 평균은 '—'이다.
제출 학생 수·확신도 보정·설명 작성 현황·정오답 현황은 대기 여부와 관계없이 해당 기록 기준을 유지한다.
